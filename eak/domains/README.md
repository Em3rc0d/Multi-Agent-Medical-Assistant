# EAK Domain Packs

Domain Packs specialize EAK without modifying Kernel Core. A pack may register capabilities, workflows, policies, knowledge descriptors, evaluation profiles and provider certification requirements.

Current incubation packs:

- `medical/` — research and professional decision-support semantics derived from Quarry #001; no autonomous diagnosis or prescribing.
- `aec/` — IFC/compliance-oriented architecture-engineering-construction stress pack.
- `legal/` — document/authority/citation-oriented legal stress pack.

A pack is declarative. Executable code belongs in provider packages or runtime adapters.
